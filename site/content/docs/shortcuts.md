---
title: Keyboard shortcuts
weight: 8
---

| Action | Shortcut |
|---|---|
| New presentation | ⇧⌘N |
| Open a presentation | ⌘O |
| Save | ⌘S |
| Export PDF | ⌘E |
| Export PowerPoint, editable | ⇧⌘E |
| Editor view | ⌘1 |
| Presenter view | ⌘2 |
| Show or hide the preview | ⌘P |
| Show or hide the notes | ⇧⌘O |
| Show or hide the inspector | ⌥⌘I |
| Present from this slide | ⌘↩ |
| Present from the start | ⇧⌘↩ |
| Next or previous slide, anywhere | ⌥PageDown, ⌥PageUp |

In the presenter view, the arrow keys, Page Up, Page Down, Space, Home and
End move between slides. For the slideshow's keys, see
[Presenting](../presenting#the-slideshow).
