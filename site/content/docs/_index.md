InkStudio is a Mac app for [inkpress](https://inkcheck.github.io/inkpress/)
presentations: folders of Markdown slides, one file per slide, styled by a
template pack. It edits them with a live preview, presents them, and exports
them to PDF and PowerPoint. The slides stay plain Markdown files, so you can
also edit them in another editor, keep them in git, and build them with the
`inkpress` command.
